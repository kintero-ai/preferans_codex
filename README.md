# Преферанс — свой стол

Браузерная игра на русском языке: один человек и два бота. Адаптивный интерфейс для мыши и сенсорного экрана. Без внешних библиотек, регистрации и платных сервисов.

## На компьютере

Откройте `index.html` в браузере. Игра работает без интернета.

## На смартфоне

1. Установите Node.js на компьютер, если он ещё не установлен.
2. В папке проекта выполните `npm start` (или `node server.cjs`).
3. Подключите телефон и компьютер к одной Wi-Fi сети.
4. Откройте на телефоне адрес, который сервер выводит после «Смартфон», например `http://192.168.1.10:8080`.
5. Если Windows предложит разрешить доступ, разрешите его для частной сети.

Компьютер должен оставаться включённым. Для игры на телефоне без компьютера файлы `index.html`, `style.css`, `engine.js` и `app.js` можно разместить на любом статическом веб-хостинге. Публикация в интернете не выполнена.

## Возможности

- Торги, прикуп, снос, выбор контракта, вист/пас, десять взяток.
- Контракты 6–10, без козыря, мизер, распасы с мастями прикупа на первых двух взятках.
- Контроль очереди, обязательной масти и козыря.
- Пуля, гора, взаимные висты, итог и история раздач.
- Выбор пули на 10, 15 или 20 очков. Партия завершается автоматически, когда все три игрока закроют пулю.
- Помощь в закрытии пули: излишек успешной игры идёт сопернику с наибольшей незакрытой пулей, за каждое очко помощи начисляются 10 вистов на получателя. При равенстве выбирается ближайший по очереди хода. Оставшийся после закрытия всех пуль излишек списывается с горы разыгрывающего (гора может стать отрицательной).
- Итоговая таблица: места, игроки, пуля, гора, разница взаимных вистов и итог. Победитель определяется по точному итоговому результату; при равенстве объявляется ничья. Отображение округлено до десятых долей виста.
- Пауза и три скорости ботов.
- Автоматическое сохранение в localStorage. Сохранение индивидуально для браузера и адреса; между устройствами не синхронизируется.
- Боты оценивают собственные карты и карты текущей взятки. Они не читают скрытые руки соперников. Алгоритм эвристический, без турнирной силы и полного учёта вышедших карт.

## Правила

Это домашняя сочинка до закрытия выбранной пули всеми игроками. Ограничения по числу раздач нет. Все соглашения доступны по кнопке «?»: закрытый розыгрыш, без полвиста, мизера без прикупа и прогрессии распасов. Когда один защитник пасует, оба продолжают управлять своими картами, а вистующий отвечает за общие обязательства защиты. При двух вистах обязательство делится поровну. Этот вариант не заявляется как полный турнирный кодекс.

Победитель — игрок с наибольшим итогом в вистах, а не первый закрывший свою пулю. Итог: разница пули и горы относительно среднего по столу × 10, плюс исходящие висты, минус входящие. Места при равенстве: 1, 1, 3 или 1, 2, 2.

Сохранения предыдущей версии с фиксированным числом раздач автоматически продолжаются до пули 20. Рука, запись и история сохраняются. Размер пули новой партии выбирается кнопкой «Новая партия».

Основа: [Кодекс преферанса](https://www.pocketpref.ru/pref/rules/rules.phtml). Стоимость игр и распасов сверена с [правилами сочинки](https://pref-game.ru/rules_sochi.htm).

## Проверка

`npm test` или `node --test tests/*.test.cjs` — проверка правил, 300 полных автоматических раздач и 9 полных партий до пули 10 / 15 / 20. Проверяются помощь, излишек, автоматическое завершение, результаты, ничья и перенос старых сохранений.

`server.cjs` — локальный сервер на порту 8080. Никакие зависимости устанавливать не требуется.

Дополнительно `node tests/browser.cjs` проверяет интерфейс в Chrome с помощью Playwright (для этой проверки нужен установленный Playwright; его путь можно указать переменной `PLAYWRIGHT_MODULE`). Проверяются экраны 320, 390, 740 и 1366 пикселей, выбор всех размеров пули, снос, окна, сохранение, последняя раздача, итоговая таблица, победитель, ничья и новая партия. Локальные PNG-снимки проверки исключены из Git.
